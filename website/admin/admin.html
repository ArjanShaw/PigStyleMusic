Custom Labels

How to Use Custom Labels

Enter one label per line. Each line will be printed on a separate label using the same dimensions as price tags. Supports multiple lines per label by using the format: Line 1|Line 2|Line 3 (use pipe | to separate lines). Lines starting with GC- will render as scannable barcodes.

Print Gift Card Barcodes

Generate 60 gift card barcodes and populate the text area below. Then use "Generate PDF" to print.

Barcodes will be placed in the text area below

Enter Custom Labels

Use | (pipe) to create multiple lines on a single label. Each line will be centered separately. Lines starting with GC- will render as scannable barcodes.

Label Printing Information:

  • Uses the SAME label dimensions as price tags (configured in Admin Config)
  • Each line of text is centered on the label
  • Use | (pipe) to create multi-line labels (up to 5 lines)
  • Lines starting with GC- will render as scannable Code128 barcodes
  • Starting position (Row, Column) determines where on the sheet printing begins
  • Labels are arranged left-to-right, top-to-bottom on the sheet
  • Sheet layout: 4 columns × 15 rows = 60 labels per page
